# IGrow PDF — downloads

IGrow's in-house PDF editor. This repository holds only the installers. The source code is private.

## Install

Download the latest version from **[Releases](../../releases/latest)**:

| Computer | File |
|---|---|
| Windows 10/11 | `IGrow-PDF-Setup-x.y.z.exe` |
| Mac with Apple chip (M1–M4) | `IGrow-PDF-x.y.z-arm64.dmg` |
| Mac with Intel chip | `IGrow-PDF-x.y.z-x64.dmg` |

The app isn't code-signed yet, so you'll see a security warning the first time you open it:
- **Windows:** More info → Run anyway.
- **Mac:** right-click the app → Open.

## Updates

- **Windows** updates itself. It checks for new versions in the background and shows **Restart now** when an update is ready.
- **Mac** shows a message when a new version is available, with a link to download it.
